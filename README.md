# CRM Process Flow — Lead to Sales Order

## 📊 Project Overview

A process flow illustrating how a record moves through the **CRM from initial contact to a completed Sales Order in SAP**.

The flow covers lead creation, opportunity conversion, CRM-SAP integration, follow-up scenarios, rejection paths and the final Closed Won outcome.

## 🎯 Business Objectives

The process flow is designed to provide a clear understanding of:

* How a contact progresses to a CRM Lead
* How a Lead is converted into an Opportunity
* How the CRM process connects with SAP
* How an SOF is created in SAP using the same CRM Reference ID
* How the SOF is linked back to CRM
* How the Sales Order is created
* How rejected records are handled
* Where follow-up actions may occur during the process
* How the process reaches the final Closed Won stage

## 🔄 Process Flow

**Contact Generated → Lead Created → Converted to Opportunity → SOF Created in SAP → SOF Linked Back to CRM → Sales Order Created → Closed Won**

The flow also includes:

* **Rejected** paths at relevant stages
* **Follow-Up** loops for records requiring further action
* CRM-to-SAP process integration
* CRM Reference ID continuity between systems

## 💼 Key Areas Demonstrated

* CRM Process Mapping
* Lead & Opportunity Lifecycle
* CRM-SAP Integration
* Business Process Analysis
* Process Flow Documentation
* Exception & Rejection Handling
* Follow-up Process Analysis
* Cross-system Process Understanding
* Business Process Visualization

## 📌 Portfolio Context

This project demonstrates the end-to-end business process connecting **CRM and SAP**, from lead generation and opportunity conversion through Sales Order creation.

It highlights the different process stages, system touchpoints, follow-up scenarios and exception paths involved in the journey.
